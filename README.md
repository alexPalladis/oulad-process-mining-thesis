# OULAD Process Mining Thesis

Companion repository for the MSc thesis:

> **Behavioral Pattern Analysis of Students Using Process Mining Techniques: A Comparative Study of Successful and Unsuccessful Students, in Terms of Academic Performance, in Distance Learning Environments**
> Alexandros Palladis — MSc in Software Engineering for Web and Mobile Applications, University of Thessaly
> Supervisor: Vasileios Gerogiannis · Second reader: Ilias Sawas

This repository contains the Python scripts used for data preprocessing, statistical analysis, process discovery, conformance checking, and performance-based enhancement reported in the thesis. It is provided to support the transparency and reproducibility of the results.

---

## Data — not included in this repository

This project uses the **Open University Learning Analytics Dataset (OULAD)**, a public dataset released by Kuzilek, Hlosta, & Zdrahal (2017) under a **CC-BY 4.0** license.

**The raw dataset is not redistributed here.** Download it directly from the official source:

📎 **https://analyse.kmi.open.ac.uk/open_dataset**

After downloading, place the seven CSV files in `data/raw/` before running any script.

```
.
├── data/
│   ├── raw/                     # OULAD CSV files (download separately, see above)
│   └── processed/               # Weekly event logs generated by scripts/02_eventlog/
│
├── scripts/
│   ├── 01_statistics/           # Chapter 3: control-flow, organizational and performance
│   │                            # perspectives, four-group comparison, demographics
│   ├── 02_eventlog/             # Weekly event log construction, XES export for ProM
│   ├── 03_process_mining/       # Chapters 3.6, 4, 5: DFG, Petri net discovery (Inductive
│   │                            # Miner), cross-group conformance checking, daily-granularity
│   │                            # robustness check
│   └── 04_enhancement/          # Chapter 6: enriched event log, milestone model,
│                                # active days per phase; robustness check for Section 3.4.1
│
├── statistics/                  # Pre-computed outputs of 01_statistics
├── figures/                     # Pre-computed DFG and Petri net figures
├── enhancement/                 # Pre-computed outputs of 04_enhancement
│
└── README.md
```

When the scripts are run, their outputs are written to `results/` (created automatically). The folders `statistics/`, `figures/`, and `enhancement/` contain the outputs reported in the thesis.

## Requirements

- Python 3.9+
- [pandas](https://pandas.pydata.org/), [numpy](https://numpy.org/), [scipy](https://scipy.org/)
- [pm4py](https://pm4py.fit.fraunhofer.de/)
- [Graphviz](https://graphviz.org/) (system package, needed by pm4py to save Petri net and DFG figures)

Install the Python packages with:

```bash
pip install pandas numpy scipy pm4py
```

The independent cross-validation in [ProM 6.15](https://promtools.org/) (Sections 3.6 and 4.1, Appendix D) was carried out separately; ProM is not a Python dependency and must be installed manually to reproduce that step.

## How to Reproduce

Run each script from its own folder, in the order below.

1. **Download the data** from the official source above and place the CSV files in `data/raw/`.

2. **Build the weekly event logs** (Section 3.2).
   ```bash
   cd scripts/02_eventlog
   python build_all_eventlogs_weekly.py
   python export_xes.py          # optional: XES files for ProM
   ```

3. **Statistical analysis** (Chapter 3).
   ```bash
   cd scripts/01_statistics
   python control_flow.py
   python organizational.py
   python performance.py
   python effect_sizes_3perspectives.py
   python control_flow_4groups.py
   python control_flow_pairwise.py
   python demographics_analysis.py
   ```

4. **Process discovery and conformance checking** (Chapters 3.6, 4 and 5).
   ```bash
   cd scripts/03_process_mining
   python discover_dfg.py
   python discover_petri.py
   python discover_all.py
   python conformance_alignments.py   # uses the models saved by discover_all.py
   python daily_flower_check.py
   ```

5. **Performance-based enhancement** (Chapter 6).
   ```bash
   cd scripts/04_enhancement
   python discover_milestone_model.py
   python enhance_active_days.py      # uses the enriched logs of the previous step
   python check_ch3_censoring.py
   ```

The course presentations and outcome groups processed by the scripts of `03_process_mining/` and `04_enhancement/` are set in the `COURSES` and `GROUPS` variables at the top of each file; by default, these are the two indicative courses of the thesis (AAA-2014J, BBB-2013J).

---

## Scope note

The statistical analysis of Chapter 3 covers all 22 course presentations of OULAD. Process discovery, conformance checking, and enhancement (Chapters 4–6) were applied to two indicative courses, one small (AAA-2014J) and one large (BBB-2013J); the scripts can be applied to other courses by editing the configuration variables at the top of each file.
