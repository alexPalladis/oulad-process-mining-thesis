# OULAD Process Mining Thesis

Companion repository for the MSc thesis:

> **Analysis of Student Behavioral Patterns Using Process Mining Techniques: A Comparative Study of Successful and Unsuccessful Students, in terms of their Academic Performance, in Distance Education Environments**
> Alexandros Palladis — MSc in Software Engineering for Web and Mobile Applications, University of Thessaly
> Supervisor: Vasileios Gerogiannis · Second reader: Ilias Sawas

This repository contains the Python scripts used for data preprocessing, statistical analysis, process discovery, and conformance checking reported in the thesis. It is provided to support the transparency and reproducibility of the results.

---

## Data — not included in this repository

This project uses the **Open University Learning Analytics Dataset (OULAD)**, a public dataset released by Kuzilek, Hlosta, & Zdrahal (2017) under a **CC-BY 4.0** license.

**The raw dataset is not redistributed here.** Download it directly from the official source:

📎 **https://analyse.kmi.open.ac.uk/open_dataset**

After downloading, place the seven CSV files in `data/raw/` (see [Repository Structure](#repository-structure) below) before running any script.

## Requirements

- Python 3.9+
- [pandas](https://pandas.pydata.org/)
- [scipy](https://scipy.org/)
- [pm4py](https://pm4py.fit.fraunhofer.de/)

Install with:

```bash
pip install pandas scipy pm4py --break-system-packages
```

For the independent cross-validation step (Chapter 3.6), [ProM 6.15](https://promtools.org/) was used separately — it is not a Python dependency and must be installed manually if you wish to reproduce that step.

## How to Reproduce

1. **Download the data.** Get the OULAD CSV files from the official source above and place them in `data/raw/`.
2. **Build the event logs.**
   ```bash
   cd scripts/02_eventlog
   python build_all_eventlogs_weekly.py
   ```
   This generates one event log per course-presentation in `data/processed/`.
3. **Run the statistical analysis** (Chapter 3 of the thesis).
   ```bash
   cd scripts/01_statistics
   python analyze_all.py
   python analyze_4groups.py
   python pairwise_4groups.py
   python organizational.py
   python performance.py
   python demographics_analysis.py
   ```
   Results are written to `results/statistics/`.
4. **Run process discovery and conformance checking** (Chapters 4–5).
   ```bash
   cd scripts/03_process_mining
   python discover_all.py
   python conformance_all.py
   ```
   Edit the `COURSES` and `GROUPS` variables at the top of each script to control which course presentations and outcome groups are processed — by default these are set to the two indicative courses used in the thesis (AAA-2014J, BBB-2013J).

---

## Scope note

The full statistical analysis (Chapter 3) was applied to all 22 course presentations in OULAD. Process discovery and conformance checking (Chapters 4–5) were applied to two indicative courses due to computational cost; the scripts in `03_process_mining/` are written to generalize to any subset of courses by editing the configuration variables at the top of each file.
